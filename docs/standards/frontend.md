

# 前端规范

适用于前端项目；React / TypeScript / Vite / Ant Design 专项规则仅在采用对应技术时适用；与根目录 [AGENTS.md](../../AGENTS.md) 一并遵守，全局约束和优先级以入口文件为准。

## 前端代码规范：React + TypeScript + Vite + Ant Design
以项目实际技术栈、版本和目录为准，不为套用规范替换框架、组件库或状态方案。

### 技术栈与目录
- 使用 项目现有版本的 React 函数组件和 Hooks、TypeScript 严格模式、Vite、React Router；页面按需使用 `lazy` 和 `Suspense` 加载。
- 沿用项目目录，分别组织接口类型、请求客户端、业务页面与公共组件，不强制调整现有目录；类型引用使用 `import type`；外部数据和异常优先使用 `unknown` 并收窄类型，避免使用 `any` 绕过检查；局部交互使用 `useState`。
- 共享状态沿用项目已有方案（如 Context + `useReducer`），通过 action 更新；重复文案、选项、类型列表提取为模块级常量或纯函数；仅在实际复用时抽公共组件。

- ❌ 禁止直接修改 state、数组或嵌套对象。
- ❌ 禁止增加单次使用的抽象层。

### 组件与请求
- 优先使用现有 Ant Design 的 Form、Table、Menu、Tabs、Modal、Drawer、Tooltip、Splitter 等组件；图标统一使用 `@ant-design/icons`，不手写替代其标准交互。
- 复用项目已有表格、编辑器、帮助提示和面板封装；只封装业务差异；请求统一调用项目请求客户端，由其处理认证信息、返回体和业务异常；异步读取使用 `AbortController`、请求序号或失效标记，避免组件卸载后更新及旧响应覆盖新状态。
- 提交操作使用 loading 和并发保护；`useEffect` 明确依赖并清理请求、事件和定时器；列表和树节点优先使用稳定业务 ID，避免增删排序后状态错位。

- ❌ 禁止重复实现组件库已有能力。
- ❌ 禁止在页面内重复实现请求协议或另加 axios。

### 样式与布局
- 全局主题与基础样式按项目约定集中维护；优先配置主题 token，页面差异使用明确的作用域，避免反复追加相互覆盖的全局选择器；沿用项目已有色彩、背景与字体；等宽字体用于代码和表达式；以项目目标设备为基准。
- 紧凑展示配置，避免重复面包屑、模块大标题和独立辅助按钮行；相关操作放在对应面板工具栏；调试沿用统一工作区和可拖动分隔线，限制在可视高度内，编辑与预览内容内部滚动；表格列宽按内容确定，为下拉箭头与清空按钮留空间。
- 标签列约容纳六个汉字，类型列容纳最长类型名称；固定定位列与操作列，保留嵌套字段展开、折叠能力。

- ❌ 禁止未经明确要求新增主题、装饰动画或更换字体。
- ❌ 禁止扩展未要求的终端适配。

### 交互与反馈
- 动作名称在按钮、弹框和反馈中保持一致；删除使用 danger 样式，辅助操作弱化；操作不可执行时提示具体原因，避免发送无效请求；导入、解析、预览等按钮并入对应配置工具栏；低频操作收进“更多”；避免同时存在多个争抢注意力的主按钮。
- 使用 Ant Design 的上下文弹框和 message 提供确认与反馈；提交期间防止重复执行及误关闭；普通说明优先通过字段或分组旁的 项目帮助提示组件 展示，避免重复「？」和常驻备注；错误、风险及必须立即知道的信息直接展示。
- 只读版本保持正常文字与控件外观；保存、发布的后端字段错误通过项目统一错误映射机制处理，错误字段或行及所属模块标红，定位首个出错模块；必要时展开错误分组或嵌套字段；JSON 编辑统一复用项目 JSON 编辑器，打开时默认格式化合法 JSON。
- 调试结果默认表格预览，支持树形展开、字段搜索和 JSON 切换；复制结果与调试参数使用统一反馈；输入控件提供可识别的 label 或 `aria-label`，图标按钮必须有操作名称；悬停帮助可键盘聚焦，保留焦点样式并尊重减少动态效果设置。

- JSON 编辑器保留具体错误信息。

- ❌ 禁止使用 `window.confirm` 或 `alert`。
- ❌ 禁止在左侧模块导航增加说明「？」。
- ❌ 禁止修改只读版本配置。
- ❌ 禁止因只读限制禁用查看、展开、复制或调试操作。
- ❌ 禁止 JSON 编辑器自动改写无效 JSON 输入。
- ❌ 禁止显示“JSON 格式正确”的常驻提示。

### 编译与开发服务
- 使用项目现有包管理器、lockfile 和构建脚本；按配置执行类型检查和构建；分包沿用项目构建配置，按实际依赖与加载需求划分。

- ❌ 禁止擅自切换项目包管理器或替换 lockfile。
- ❌ 禁止仅通过提高告警阈值掩盖包体积问题。
- ❌ 禁止仅因文档变更执行编译或重启。
- ❌ 禁止将编译通过表述为测试通过。
