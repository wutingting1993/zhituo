# 智拓报表接口需求：规划视角—规划来源结构

## 需求范围

仅整理规划来源结构的接口需求，不开发接口、前端或数据库。取消规划洞察，不提供洞察统计、评价或建议。

按当前筛选范围内的分行规划总数降序，返回前topN个分行，展示各分行规划总数及三类来源构成。不足topN个时返回实际数量。

## 接口与检索条件

下列接口路径已实现，实现状态按当前代码记录。使用 POST 和 JSON body。

| 接口 | 用途 | 入参 | 返回内容 |
| --- | --- | --- | --- |
| `/api/v1/reports/plan-sources` | 获取规划来源结构 Top N | topN可选；开始、结束日期必填；分行编号、支行编号、等级、技能编号列表可选 | 按排名排列的分行编号、名称、规划总数及三类来源数量 |

- 参数沿用现有接口的 `startDate`、`endDate`、`bbkId`、`orgId`、`level`、`skillIds`。技能多选，多个技能之间为“或”，其余单选；未选表示全部。
- 先应用全部顶部筛选条件，再按分行统计和排名，不能先取全行 Top N 再筛选。
- 选择支行时，仅统计该支行范围内的数据，仍按其所属分行返回，不扩展为整个分行的数据。
- 日期使用排程 `swe_plan_sence_cron.execute_day`，包含开始日和结束日；不另加当前发布状态或有效期限制。
- 检索选项及参数错误规则复用现有接口；开始日期晚于结束日期时返回参数错误；不校验分支行匹配关系，不匹配时正常查询。

## 来源与排名口径

| 数据 | 技术口径 |
| --- | --- |
| 分行 | 规划目标人员关联人员表后取 `first_bbk_id`，按分行编号分组，名称仅用于展示 |
| 我的关注规划数 | 主表 `source_label` 为“我的关注”，在当前分行及全部筛选条件下按 `plan_id` 去重 |
| 分行关注规划数 | 主表 `source_label` 为“分行中台”，按同一范围的 `plan_id` 去重；返回及展示名称为“分行关注” |
| 行长关注规划数 | 主表 `source_label` 为“行长关注”，按同一范围的 `plan_id` 去重 |
| 规划总数 | 仅保留上述三类来源，在当前分行及全部筛选条件下按 `plan_id` 去重；等于三类来源数量之和 |
| Top N | 分行规划总数降序取前topN项；总数相同时按分行编号升序，不扩展并列名额 |
| 来源占比 | 页面以各来源数量÷该分行规划总数×100%计算，仅用于堆叠条展示；接口返回数量，不额外返回占比字段 |

- NULL、空字符串及其他来源不统计；`source_id` 不用于三类关注来源分类。
- 同一规划跨日期、技能、人员或支行，在同一分行只计1条；分行规划数不能累加支行规划数。
- 同一规划涉及多个分行时，各分行分别去重计数；Top N 各分行数量之和不作为全行去重规划总数。
- 仅返回规划总数大于0的分行；筛选范围内没有符合条件的数据时返回空列表，不补零、不补足topN项。
- 通过可选入参 `topN` 指定返回数量，未传或null默认5；必须为正整数，不设额外上限。不新增分页或下钻能力。

## 数据来源与匹配规则

沿用 [智拓报表接口需求](report-api-requirements.md) 的完整数据匹配规则，以及 [分支行规划覆盖需求](report-plan-coverage-requirements.md) 的来源分类、日期及机构归属口径，不另建一套统计逻辑。

- 人员与机构：`swe_wealth_plan_targets.sap_id = rm_jkh_user_info.user_id`，分行取 `first_bbk_id`，支行取 `org_id`，等级取 `pst_lvl`。不按规划负责人的机构替代目标人员机构。
- 规划、目标、场景要求 `deleted=0`，技能要求 `source_id=RMASSIST`；任务、排程及执行匹配沿用现有规则，每任务每天取最新一次执行，且执行时间不早于规划创建时间。
- 没有执行记录的规划不纳入；有符合条件的执行但没有推荐结果的规划仍计入。结果和客户行为不作为额外的规划纳入条件。
- 来源取 `swe_wealth_plans.source_label`，严格匹配三类指定值；“分行中台”映射为“分行关注”。

原型“生效中规划”在本需求中仍指沿用存量统计范围的规划，不代表额外判断当前发布状态或有效期。

## 验收要求

- 不提供规划洞察，仅提供规划来源结构 Top N。
- 相同顶部条件下，每个分行的规划总数及三类来源数量与覆盖表对应分行一致。
- 先筛选后排名，按规划总数降序返回最多topN个分行；并列时按分行编号升序，不扩展名额。
- 每个分行独立按规划编号去重，三类来源之和等于该分行规划总数，不能累加支行统计值。
- 选择某个分行或支行后，仅返回筛选范围内符合条件的数据；不返回筛选范围外的零值分行。
- 不足5项返回实际数量，无数据返回空列表。
- 接口及并列排序规则已实现，实现状态按当前代码记录。
