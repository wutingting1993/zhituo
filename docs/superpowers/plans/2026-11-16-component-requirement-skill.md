# 通用组件需求分析技能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 创建通用技能，在组件需求分析中先核对知识与用户描述，再有依据地澄清。

**Architecture:** 单个 SKILL.md 定义证据分类、分析顺序与条件化回答结构；不依赖项目字段、外部服务或报表案例。

**Tech Stack:** Markdown、YAML frontmatter。

**Spec:** 本轮用户批准的通用简版设计：用途、现状、变化、差异、核实项、技术依据、关键澄清；不机械提问，不扩大授权。

## Global Constraints

- 不修改业务代码、数据库或既有上下文接口。
- 不新增、运行项目单元/e2e测试；不自动提交。
- 写入个人技能目录前遵守沙箱审批；先在项目 docs/skills 下形成可审阅文件。

## Review Focus

- 已有查询能力不等于提交能力或页面已展示。
- 旧资料、PENDING 和冲突不转成当前已核实事实。
- 用户新决定与既有能力分开，未知不等于不存在。
- 普通表单、预约等场景不强套统计术语。
- 已确认内容不重复追问，缺少 ID 时用可定位来源。
